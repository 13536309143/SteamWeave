# Changelog

## 1.2.0 — 2026-10-13

- Add quadratic image-curve descriptors, strictly causal curve history and repair resets.
- Select forecasting heads using training-only grouped or forward inner validation.
- Route missing current curves through original augmented expert fusion; retain original checkpoints.
- Publish 18 paired outer comparisons, 324 current-modality pressure conditions and inner-selection audits.
- Improve grouped MAE from 4.853 to 4.089 adu and the serving holdout from 5.094 to 4.077 adu. Temporal candidates worsen MAE and are not deployed as the future-period checkpoint.
- Disclose exploratory protocol refinement, wider predictive intervals and diagnostic-only original experts when the new head is active.
- Add causal-history, repair-reset, mask, forward-validation and serving-route regression tests.
